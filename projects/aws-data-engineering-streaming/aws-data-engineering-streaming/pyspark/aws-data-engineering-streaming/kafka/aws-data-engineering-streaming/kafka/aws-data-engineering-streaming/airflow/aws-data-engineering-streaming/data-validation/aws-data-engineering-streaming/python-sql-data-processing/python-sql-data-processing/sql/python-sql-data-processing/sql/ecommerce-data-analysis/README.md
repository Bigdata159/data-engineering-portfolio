# E-commerce Data Analysis

## Overview

This project demonstrates an e-commerce data analysis workflow using Python and SQL.

The project processes customer, transaction, and user activity data to generate business-oriented metrics.

## Technologies

* Python
* SQL
* Pandas
* PostgreSQL
* Power BI

## Dataset

The project uses synthetic e-commerce data containing fields such as:

* Customer ID
* Transaction ID
* Product ID
* Transaction Date
* Product Category
* Transaction Amount
* Customer Activity

## Analysis

The project demonstrates:

* Customer transaction analysis
* Revenue analysis
* Customer activity analysis
* Product performance
* Transaction trends
* Data quality validation

## Business Metrics

* Total Revenue
* Average Order Value
* Number of Customers
* Number of Transactions
* Revenue by Product Category
* Customer Purchase Frequency

## Data Quality

Python and SQL checks identify:

* Duplicate transactions
* Missing customer information
* Invalid transaction amounts
* Inconsistent records

## Reporting

Processed datasets can be consumed by Power BI for dashboard development.

## Note

This portfolio project uses synthetic data and does not contain proprietary company information.
